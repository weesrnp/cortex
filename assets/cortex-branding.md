# Cortex — identidade visual

O símbolo combina um **C aberto** com um núcleo e quatro conexões. A forma sugere memória consultável, grafo de notas
e acesso local.

## Arquivos

- `cortex-banner.png` — banner horizontal do topo do README.
- `cortex-mark.svg` — símbolo escalável para avatar, favicon (o explorer web usa este) ou documentação.
- `cortex-social.png` — prévia para redes sociais (1280x640), para Settings → Social preview no GitHub.

## Tipografia e uso

Use uma sans geométrica limpa para **CORTEX** em caixa alta, com espaçamento moderado. O subtítulo é **MEMÓRIA
SEMÂNTICA LOCAL**. Em tamanhos pequenos, use só o símbolo e deixe uma margem livre de pelo menos 1/8 da largura ao
redor dele. Sobre fundo claro, use o símbolo dentro do quadrado escuro.
